# تطبيق مركز السنة للعلوم الشرعية وتأهيل الدعاة

تطبيق Flutter يعمل **بدون إنترنت بالكامل** (قاعدة بيانات محلية SQLite على الجهاز)،
عربي بالكامل واتجاهه من اليمين إلى اليسار.

## الحسابات

- **الإدارة (مستخدم واحد):** عند أول تشغيل يطلب التطبيق إنشاء حساب المدير
  (اسم مستخدم + كلمة مرور). هذه البيانات تُستخدم لاحقاً للدخول كإدارة.
- **المعلم:** الإدارة تنشئ له حساباً من تبويب «المعلمون»، ثم يدخل باسم المستخدم وكلمة المرور.

## واجهة المعلم

بعد الدخول تظهر **4 مسارات**: مفاتيح الطلب، معارج التحصيل ①، ②، ③.
كل مسار فيه ثلاثة أقسام:

### 1) الدروس
- أول مرة: زر **«إضافة درس»** ← قائمة منسدلة لاختيار النوع:
  - **نظم** ← يُطلب عدد الأبيات.
  - **نثر** ← يُطلب عدد الصفحات.
- بعدها: زر **«تسجيل اليوم (من — إلى)»** ← يختار اليوم، يحدد الأبيات/الصفحات
  من — إلى، مع تاريخ الدرس والزمن (من — إلى).
- **مخطط دائري ملون** يظهر نسبة الإنجاز % والمتبقي لكل درس.
- **جدول تحضير الطلاب** المشتركين في المسار + زر **«إضافة طالب»**.

### 2) المتون
- قائمة طلاب المسار ← الضغط على الطالب يفتح **صفحته الخاصة**.
- في الصفحة: **إسناد متن** (اسم النظم/النثر + عدد الأبيات أو الصفحات)،
  ثم **تسجيل ما سُمع من — إلى** بكل يوم، مع مخطط دائري لنسبة ما سُمع.

### 3) القرآن
- لكل طالب **متابعة الورد القرآني اليومي**: من صفحة كذا إلى صفحة كذا (1–604).

## واجهة الإدارة

ثلاثة تبويبات:

1. **التقارير:** تقرير يومي باختيار التاريخ يشمل:
   - الدروس: ما سُجل في اليوم + مخطط دائري لنسبة إنجاز كل درس (تم/متبقي).
   - المتون: تقرير لكل طالب بما سُمع منه اليوم + مخطط إنجاز المتن.
   - القرآن: أوراد اليوم لكل طالب.
2. **المعلمون:** إضافة وحذف حسابات المعلمين.
3. **المزامنة:** نقل البيانات من جهاز المعلم إلى جهاز الإدارة.

## المزامنة بدون سيرفر (كيف تعمل؟)

التطبيق لا يحتاج إنترنت في أي وقت. لمزامنة بيانات المعلم مع الإدارة:

1. في جهاز المعلم: تبويب المزامنة ← **«تصدير ومشاركة النسخة»**
   ← يُنشأ ملف JSON بكل السجلات ويفتح شار المشاركة (واتساب، بريد، بلوتوث...).
2. في جهاز الإدارة: تبويب المزامنة ← **«استيراد نسخة»**
   ← الصق محتوى الملف ← تُدمج كل السجلات فوراً.

هذا يعطيك مزامنة حقيقية دون أي تكلفة سيرفر، والبنية مهيأة لربط سيرفر لاحقاً إن رغبت.

## البناء

```bash
flutter pub get
flutter run            # للتشغيل على جهاز موصول
flutter build apk      # لإنتاج ملف APK للتثبيت
```

يتطلب Flutter 3.24 أو أحدث.

## بنية الكود

```
lib/
├── main.dart                  # نقطة الدخول + التوطين العربي
├── core/constants.dart        # المسارات الأربعة
├── data/models.dart           # النماذج (معلم، طالب، درس، متن...)
├── data/database.dart         # قاعدة البيانات المحلية (sqflite)
├── state/app_state.dart       # حالة الجلسة + حساب التقارير
├── services/backup_service.dart  # تصدير/استيراد JSON (المزامنة)
├── widgets/
│   ├── progress_pie.dart      # المخطط الدائري (إنجاز/متبقي)
│   └── helpers.dart           # تواريخ عربية + أدوات
└── screens/
    ├── login_screen.dart      # الدخول + إعداد حساب الإدارة أول مرة
    ├── teacher_home_screen.dart  # المسارات الأربعة
    ├── track_screen.dart      # تبويبات المسار (دروس/متون/قرآن)
    ├── lessons_tab.dart       # الدروس
    ├── mutun_tab.dart         # المتون
    ├── quran_tab.dart         # القرآن
    └── admin_home_screen.dart # الإدارة (تقارير/معلمون/مزامنة)
```
